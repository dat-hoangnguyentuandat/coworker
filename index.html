Tính năng

Một trợ lý thực thụ, không phải ô chat.

ChatGPT trên web nói về code. Coworker cho nó tay — và bạn giữ quyền kiểm soát.

01 · LÀM VIỆC THẬT

Đọc file, sửa code, chạy lệnh — trên workspace thật

ChatGPT đọc và sửa file, chạy lệnh qua MCP ngay trong workspace. Xem diff và kết quả trực tiếp tại app.

  • Sửa file, diff, checkpoint hoàn tácworkspace_write_file · workspace_edit_file · rewind
  • Terminal, Git, processrun_command · git_commit · start_process
  • Tìm kiếm code thông minhworkspace_code_search · workspace_analyze

02 · NHIỀU TÀI KHOẢN

Hết quota tài khoản này, tài khoản khác tiếp tay ngay

Lưu nhiều tài khoản ChatGPT với mật khẩu và 2FA được mã hoá. Khi cần, đăng nhập tài khoản khác; Coworker chuyển phiên trong profile đó.

  • Đăng nhập tự động email/mật khẩu + OTPTOTP 2FA · credential mã hoá, không plaintext
  • Đăng nhập bằng GoogleCửa sổ riêng, người dùng tự nhập — app không chạm mật khẩu Google
  • 1 profile = 1 tài khoảnĐăng nhập mới đè cũ, binding tự cập nhật

03 · TUNNEL MÃ HOÁ

Mỗi tài khoản một đường hầm riêng vào máy người dùng

Secure MCP Tunnel nối ChatGPT tới workspace qua tunnel-client chính chủ của [OI] — mỗi tài khoản một tunnel, một Runtime API key riêng. Không mở port, không lộ IP.

  • Multi-tunnel song songmỗi tunnel một process tunnel-client riêng
  • Trạng thái từng đường hầmchạy / dừng / lỗi hiển thị riêng từng dòng
  • Key được bảo vệ trên máylưu trữ mã hoá theo cơ chế của hệ điều hành

Cách hoạt động

Từ cài đặt đến một luồng làm việc rõ ràng

Cùng một luồng mà app hướng dẫn từng bước — bản web này có tài liệu chi tiết cho từng phần.

1
Chọn workspace, bật MCP

Trỏ Coworker vào thư mục dự án. MCP server chạy local tại 127.0.0.1:3210.

2
Tạo tunnel + app Coworker trong ChatGPT

Tunnel ID + Runtime API key từ [OI] Platform, rồi tạo app chọn Connection = Tunnel. Chi tiết: Quickstart.

3
Gắn tài khoản + tunnel

Thêm tài khoản vào Đăng nhập tự động, thêm tunnel tương ứng trong Kết nối. Nhiều cặp tài khoản–tunnel chạy song song.

4
Chat, duyệt, ship

Mở ChatGPT trong app, giao việc. Thanh duyệt dưới cùng phê duyệt từng thao tác — code vào thẳng workspace.
