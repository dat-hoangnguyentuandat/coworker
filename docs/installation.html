Mở đầu

Cài đặt

Coworker chạy trên Windows 10/11 (64-bit). Cài đặt bằng bộ cài desktop và mở app để hoàn tất cấu hình workspace.

Yêu cầu

  • Windows 10/11, 64-bit
  • ~300 MB dung lượng trống
  • Tài khoản ChatGPT có quyền dùng Plugin và MCP theo chính sách tổ chức

Các bước cài đặt

  1. Chạy file Setup

    Mở Coworker.Setup.1.0.1.exe → Next → Install. App vào %LOCALAPPDATA%\Programs\coworker, shortcut ra Desktop và Start Menu.

  2. Mở app lần đầu

    Windows SmartScreen có thể hỏi vì app chưa ký chứng chỉ — bấm More info → Run anyway.

  3. Kiểm tra kết nối

    Mở mục Kết nối, bật MCP khi cần và kiểm tra trạng thái sẵn sàng.

  4. Chọn workspace

    Trỏ app vào thư mục dự án. Có thể tạo thêm workspace và task sau khi app mở.

Sau khi cài

Đi tiếp sang Quickstart để kết nối MCP và chạy lệnh kiểm tra đầu tiên. Nếu bạn dùng nhiều tài khoản ChatGPT, xem thêm Multi-account và Multi-tunnel.
