Mở đầu

Quickstart

Từ cài đặt đến tool call đầu tiên. Làm đúng trình tự, không cần đọc tài liệu nào khác trước.

Điều kiện tiên quyết

  • Coworker đã cài và mở; workspace đã trỏ vào thư mục dự án
  • Tài khoản ChatGPT có quyền dùng Apps/Connectors và cấu hình MCP theo chính sách tổ chức
  • MCP đã bật trong Coworker — kiểm tra trạng thái ở mục Kết nối

1 · Tạo tunnel trên OpenAI Platform

Tunnel là kết nối giữa ChatGPT và MCP của Coworker. Cấu hình có thể khác theo tài khoản hoặc tổ chức; xem Multi-tunnel nếu cần chạy nhiều kết nối.

  1. Đăng nhập đúng tài khoản

    Tunnel thuộc về tài khoản tạo nó. Dùng tài khoản chính cho tunnel đầu tiên.

  2. Tạo tunnel

    Mở trang quản trị tunnel theo tổ chức của bạn → Create tunnel. Đặt tên dễ nhận biết và ghi lại Tunnel ID.

  3. Tạo Runtime API key

    Mở mục Runtime API Keys, tạo key theo quyền tối thiểu cần thiết và lưu ở nơi an toàn.

  4. Nhập vào Coworker

    Vào Kết nối → thêm Secure MCP Tunnel → điền nhãn, Tunnel ID và Runtime API key → Lưu. Kiểm tra dòng trạng thái chuyển sang sẵn sàng.

Runtime API key hiển thị một lần

Mất key thì tạo key mới trên Platform và nhập đè — tunnel và các cấu hình khác không bị ảnh hưởng.

2 · Tạo app "Coworker" trong ChatGPT

App là cầu nối phía ChatGPT: nó bảo ChatGPT "có một MCP server ở đầu kia tunnel này". Tạo một lần cho mỗi tài khoản.

  1. Mở giao diện tạo app

    Trong ChatGPT, mở Apps/Connectors, chọn dấu + và tạo kết nối mới.

  2. Điền thông tin

    Đặt tên Coworker, chọn Connection = Tunnel, rồi chọn tunnel vừa tạo theo hướng dẫn của ChatGPT.

  3. Lưu kết nối

    Chọn Create hoặc Save. Không chia sẻ Runtime API key trong chat hoặc mã nguồn.

  4. Xác nhận hai đầu

    Ở Coworker, dòng tunnel chuyển Đang chạy. Trong ChatGPT, app Coworker xuất hiện trong danh sách app của chat mới.

3 · Chạy tool đầu tiên

  1. Mở ChatGPT trong app

    Chọn ChatGPT trên thanh điều hướng. Tạo chat mới và chọn app Coworker nếu ChatGPT yêu cầu.

  2. Gửi lệnh kiểm tra
    Dùng Coworker gọi workbench_status, liệt kê workspace và task,
sau đó bind vào task đang mở.
  3. Duyệt thao tác

    Nếu đang ở chế độ Hỏi trước, thanh duyệt xuất hiện trong app. Xem phạm vi rồi bấm Cho phép hoặc từ chối.

  4. Kiểm tra phía app

    Mục Hoạt động ghi lại tool call với thời gian. Workspace đã bind vào chat.
