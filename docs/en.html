Documentation

Coworker documentation

Coworker brings ChatGPT into your project workspace to read files, edit code and run commands. Choose an access mode and follow each action in the app.

Core concepts

ConceptWhat it means
WorkspaceThe project folder you give Coworker access to. You can switch workspaces and tasks in the app; access permissions apply to the selected workspace.
ProfileAn independent ChatGPT window with separate cookies. Each profile has exactly one active account.
TunnelAn outbound connection between ChatGPT and Coworker's MCP server. Manage tunnel IDs and keys in Connections; use separate configurations to keep accounts apart.

Suggested path

  1. Installation — install the app, open it and select a workspace.
  2. Quickstart — create your first tunnel and Coworker app in ChatGPT, then run a test tool call.
  3. Multiple accounts — manage ChatGPT accounts and their profiles.
  4. Multiple tunnels — give each account its own tunnel and run them side by side.
Version-specific guide

This web guide describes Coworker 1.0.1. If a label or control differs in your installed version, follow the status and instructions shown in the app.

Installation

Coworker runs on 64-bit Windows 10/11. Install the desktop app, then set up your workspace.

Requirements

  • Windows 10/11, 64-bit
  • About 300 MB of free disk space
  • A ChatGPT account permitted to use Plugin and MCP under your organization's policy

Installation steps

  1. Run Setup

    Open Coworker.Setup.1.0.1.exe → Next → Install. The app installs under %LOCALAPPDATA%\Programs\coworker and adds Desktop and Start Menu shortcuts.

  2. Open the app

    Windows SmartScreen may warn because the app is unsigned. Verify the installer source before choosing More info → Run anyway.

  3. Check Connections

    Open Connections, enable MCP when needed and confirm its ready status.

  4. Select a workspace

    Point Coworker to your project folder. You can add workspaces and tasks later.

After installation

Continue to Quickstart for the first MCP test. For several ChatGPT accounts, see Multiple accounts and Multiple tunnels.

Quickstart

Go from installation to your first tool call in this order.

Before you begin

  • Coworker is installed and open, with a project folder selected as the workspace.
  • Your ChatGPT account can use Plugin and configure MCP under your organization's policy.
  • MCP is enabled in Coworker; check its status in Connections.

1 · Create a tunnel in OpenAI Platform

A tunnel connects ChatGPT to Coworker's MCP server. Account and organization setups may differ; see Multiple tunnels if you need more connections.

  1. Sign in to the right account

    The tunnel belongs to the account that creates it. Use your primary account for the first tunnel.

  2. Create a tunnel

    Open your organization's tunnel management page → Create tunnel. Give it a recognizable name and record its Tunnel ID.

  3. Create a Runtime API key

    Open Runtime API Keys, grant only the permissions needed for the tunnel, and store the key safely.

  4. Add it to Coworker

    In Connections, add a Secure MCP Tunnel; enter its label, Tunnel ID and Runtime API key, then Save. Check that its status becomes ready.

A Runtime API key is shown once

If you lose it, create a new key in Platform and replace the saved one. The tunnel and other settings are unaffected.

2 · Create the Coworker app in ChatGPT

The ChatGPT app points to the MCP server at the other end of your tunnel. Create one app for each account.

  1. Open app creation

    In ChatGPT, go to Settings → Plugin, open the plugin management page, click +, then select New app.

  2. Fill in the details

    Name it Coworker, choose Connection = Tunnel, then select the tunnel you created using ChatGPT's instructions.

  3. Save the connection

    Choose Create or Save. Do not share the Runtime API key in chat or source code.

  4. Verify both ends

    The Coworker tunnel row should show Running. The Coworker app should appear in ChatGPT's app list for a new chat.

3 · Make the first tool call

  1. Open ChatGPT in the app

    Choose ChatGPT in the navigation bar. Start a new chat and select the Coworker app if prompted.

  2. Send a test request
    Use Coworker to call workbench_status, list workspaces and tasks,
then bind to the currently open task.
  3. Approve the action

    In Ask-first mode, review the scope in Coworker's approval bar and choose Allow or Deny.

  4. Check Coworker

    Activity records the tool call and time. The workspace is bound to the chat.

When something goes wrong

SymptomLikely causeWhat to do
ChatGPT cannot see the Coworker appThe tunnel is not running or the app is not installed in ChatGPT.Check tunnel status in Connections and install the app again in ChatGPT.
Tunnel shows ErrorWrong Runtime API key, deleted tunnel, or a blocked network.Create and enter a new key; verify that the tunnel still exists in Platform.
A tool call does not returnMCP is disabled or Coworker is closed.Enable MCP in Connections and resend the request.

Multiple accounts

Each profile is an independent ChatGPT window with separate cookies and exactly one active account. You can save several accounts, but each profile runs only one at a time.

How it works

ConceptMeaning
AccountA ChatGPT email and credentials (password, 2FA) saved encrypted with Windows DPAPI.
ProfileAn independent ChatGPT window selected from the account's profile dropdown.
BindingAn account-to-profile assignment. Only one account can be assigned to a profile at a time.

Add an account

  1. Open Auto-login

    Use the auto-login button in the profile toolbar, or the account list in account settings.

  2. Add an account row

    Enter the ChatGPT email and password. For 2FA, also enter the TOTP secret from the setup QR code; Coworker generates an OTP during sign-in.

  3. Choose a profile

    Select a profile such as ChatGPT 1. If another account is assigned to it, that account immediately changes to — None —.

  4. Using Google?

    Click Google beside “Add to list”. Coworker opens a ChatGPT window for you to sign in manually, then adds the account after detecting the session.

An account needs a profile to sign in

If its dropdown still says — None —, sign-in reports an error. Assign a profile first.

Sign in and switch accounts

  1. Automatic sign-in

    Click sign in beside an account. Coworker opens a separate window, enters email and password, then OTP if enabled. Google accounts use a manual window instead.

  2. Switch on the same profile

    Sign account B into a profile used by account A. Coworker signs A out before signing B in.

  3. Continue work

    If Coworker can retrieve A's latest conversation, it sends that content to a new chat for B. Review the context before continuing.

Sign in all

Sign in all processes assigned accounts one by one, each in its own profile. If accounts share a profile, the one signed in last takes over and the other cannot stay active.

Frequently asked questions

SituationWhat to do
The old account remains signed inCoworker detects a mismatched session and retries up to twice. If it still persists, sign in again; old cookies are cleared before the next attempt.
OTP repeatedly failsCheck the base32 TOTP secret from the QR code and enable Windows time synchronization.
Run two accounts simultaneouslyAssign them to different profiles, such as ChatGPT 1 and ChatGPT 2, with separate windows and cookies.
Delete an accountUse the delete button beside it. Its encrypted local credentials are permanently removed.

Multiple tunnels

Each ChatGPT account needs its own Secure MCP Tunnel, because a tunnel belongs to its OpenAI organization. Coworker can run multiple tunnels at once, all connecting to the same local MCP server.

Why one tunnel per account?

Account A cannot see account B's tunnel. Create one tunnel and one Runtime API key per account. In each account's ChatGPT, create its Coworker app through Settings → Plugin → plugin management page → + → New app, and point it at that account's tunnel.

ComponentPer accountNotes
Tunnel IDSeparateCreate at platform.openai.com/settings/organization/tunnels while signed into that account.
Runtime API keySeparateDo not reuse another tunnel's key; Coworker rejects it.
ChatGPT Coworker appSeparateEach account's app points to its own tunnel.
Destination MCP serverSharedAll tunnels lead to 127.0.0.1:3210 on your computer.

Add a tunnel for each account

  1. Open Connections

    Coworker → Connections → Secure MCP Tunnel. Each row shows its label, status, Tunnel ID and delete button.

  2. Get the second account's tunnel

    Sign in as account 2, visit platform.openai.com/settings/organization/tunnels, create a tunnel and a Runtime API key.

  3. Enter it in Coworker

    Below the list, enter the Account name, Tunnel ID and Runtime API key, then Save.

  4. Repeat for each account

    When MCP is enabled, all enabled tunnels start together, each with its own tunnel-client process.

Read tunnel status

StatusMeaning
RunningThe tunnel-client is connected; that account's ChatGPT can call tools.
StartingThe tunnel-client is establishing a connection, usually within seconds.
StoppedThe tunnel is valid, but MCP is off.
DisabledThis tunnel is disabled in its configuration.
ErrorThe key is wrong, the tunnel was deleted in Platform, or the network cannot connect. Hover over the log for details.

The summary displays a count such as 2/3 running. MCP logs combine all tunnels with a tunnel prefix on each entry.

Edit or remove a tunnel

  • Rename or replace a key: enter the existing Tunnel ID in the form, update the label or key, then Save. Leave the Runtime API key empty to keep the saved key.
  • Delete: use the row's delete button. This removes only Coworker's configuration; the tunnel remains in OpenAI Platform.
Do not reuse one key for two tunnels

Coworker rejects it. A key is bound to its tunnel, and reuse could disrupt the first tunnel-client session.

Security and architecture

Coworker handles real credentials and project files. This is how they are protected.

Architecture

ChatGPT (account A) ─→ Secure Tunnel ─→ tunnel-client A ─┐
                                                          ├─→ MCP server (127.0.0.1:3210) ─→ Workspace
ChatGPT (account B) ─→ Secure Tunnel ─→ tunnel-client B ─┘

Each ChatGPT connection reaches Coworker's MCP server through its tunnel-client. MCP operates on the selected workspace under the access mode configured in the app.

How credentials are protected

DataStored inProtection
Account password and 2FA secretEncrypted auto-login.jsonWindows DPAPI with an enc: prefix; decryptable only under your Windows account.
Tunnel Runtime API keyEncrypted settings.jsonWindows DPAPI; copying the file to another computer does not reveal it.
ChatGPT sessionCookies in each profile partitionIndependent profile windows keep cookies separate.

Approval flow

  1. ChatGPT calls a tool

    For example, workspace_edit_file travels through a tunnel to the app's MCP server.

  2. MCP checks the allowlist

    The tool must be allowed. In Ask-first mode, file edits, shell commands and Git actions wait for your approval.

  3. The app shows an approval bar

    Review the diff, command and directory before anything runs.

  4. You decide

    Allow executes the operation and creates an undo checkpoint; Deny returns an error to ChatGPT so it can adjust its approach.

Important boundary

A workspace path is not a sandbox for shell commands. Review commands and operating-system permissions before approving execution.

What Coworker does not do

  • It does not store plaintext passwords, including in logs.
  • It does not type your Google password into a hidden window; Google sign-in is always manual.
  • It does not open an inbound port on your computer; tunnel-clients connect outward.
  • Workspace operations go through the app's MCP path. Check tunnel status, logs and network policy before using it in a sensitive environment.
