1.0.0 — Bản phát hành đầu tiên

  • Quản lý workspace và task trong ứng dụng desktop.
  • Kết nối ChatGPT với công cụ MCP để đọc tệp, chỉnh sửa mã, chạy lệnh và thao tác Git.
  • Nhiều profile ChatGPT độc lập, hỗ trợ chuyển qua lại khi làm việc.
  • Các chế độ quyền Hỏi trước, Tự động và Toàn quyền; theo dõi thao tác trong Hoạt động.
  • Giao diện sáng/tối, hướng dẫn trong app và tài liệu web bằng tiếng Việt, tiếng Anh.
