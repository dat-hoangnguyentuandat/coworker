Documentation

Coworker, in plain English.

A desktop workspace for using ChatGPT with your real project files, tasks and tools. This guide follows the current app interface and avoids assuming a specific account or network setup.

Core concepts

TermMeaning
WorkspaceThe project folder Coworker works with.
ProfileAn independent ChatGPT window with its own sign-in session.
TunnelAn outbound connection between ChatGPT and Coworker's MCP tools.

Suggested path

  1. Installation — install Coworker and select a workspace.
  2. Quickstart — connect ChatGPT and try a first task.
  3. Multiple accounts — use separate profiles for separate accounts.
  4. Multiple tunnels — configure separate connections when needed.

Installation

  1. Install the Windows desktop app

    Run the latest Coworker installer and open the app. If Windows shows a SmartScreen warning, verify the installer source before continuing.

  2. Choose a workspace

    Select the project folder that Coworker may work with. You can add, rename or remove workspaces later.

  3. Review MCP status

    Open Connections. MCP-dependent controls stay disabled until MCP is enabled and ready.

Quickstart

  1. Create a task

    Use New task in the sidebar and give it a short, specific name.

  2. Connect ChatGPT

    Open Connections, configure the MCP connection required by your ChatGPT workspace, then confirm the status is ready.

  3. Ask for a bounded change

    Start with a small request such as listing a folder or explaining one file. Include the workspace and task context.

  4. Review before execution

    In Ask-first mode, inspect the requested scope in the approval bar and choose Allow or Deny. Automatic and Full modes are available when appropriate.

Workspaces and tasks

A workspace is a local project folder. A task is the unit of work inside that workspace. The sidebar keeps both visible so you can switch context without recreating your project configuration.

  • Create, rename and delete workspaces from the workspace menu.
  • Create, rename and close tasks from the task menu.
  • Use a separate task when you need a clean context or want another conversation to continue independently.

Profiles and multiple accounts

Each profile is an independent ChatGPT browser session with its own cookies and one active account. You can keep several profiles open and switch between them without recreating workspaces or tasks.

  1. Create a profile

    Use the profile selector in the app toolbar, then choose Add profile. Give it a name that identifies the account or purpose.

  2. Sign in

    Open ChatGPT in that profile. Use the supported sign-in method for the account. If you save credentials for automatic sign-in, review what is stored in the app first.

  3. Switch safely

    Select another profile from the toolbar. Return to the first profile to inspect its conversation and task status; activity is not copied between accounts.

MCP and tunnels

MCP connects ChatGPT tools to Coworker. A tunnel is an outbound connection used when your ChatGPT setup requires remote MCP access.

  1. Enable MCP

    In Connections, turn on MCP and confirm that the local server reports Ready.

  2. Create a tunnel ID

    In OpenAI Platform, select the correct organization and ChatGPT workspace, then create a tunnel. Copy its ID.

  3. Create a Runtime API key

    Open Organization API Keys → Runtime API Keys. Give the key only the tunnel permissions required by your organization, then copy it once.

  4. Configure Coworker

    Enter the tunnel ID and Runtime API key in Connections. Start the tunnel and verify its status before creating or using the ChatGPT app.

Keep keys private

Never paste a Runtime API key into ChatGPT, screenshots, source files or support messages. Rotate a key if it may have been exposed.

Security model

Coworker shows tool activity and applies the selected access mode. Ask-first is the safest default for unfamiliar work. Automatic and Full modes reduce prompts but grant more autonomy, so use them only for trusted tasks.

Important boundary

A workspace path is not a sandbox for shell commands. Review commands and the current operating-system permissions before allowing execution.

Troubleshooting

SymptomWhat to check
MCP controls are disabledEnable MCP in Connections and wait for the ready status.
ChatGPT cannot see CoworkerConfirm the connection configuration, tunnel status and the selected ChatGPT workspace.
A task appears stuckOpen Activity, inspect the pending tool call and return to the profile that owns the conversation.
